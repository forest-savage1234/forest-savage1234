## Selected work

### [Claim Review & Metabolic Engineering Forensics](https://github.com/forest-savage1234/metabolic-engineering-forensics)

Tools for examining the evidence behind quantitative scientific claims. My work includes a browser calculation checker, a verification protocol, structured case studies, and a Python manifest verifier. The browser prototype replays declared calculations while keeping unresolved measurement and context questions visible.

[Try Claim Review](https://forest-savage1234.github.io/casefile-provenance-demo/claim-review/) · [Browser edition and example](https://github.com/forest-savage1234/casefile-provenance-demo/tree/main/claim-review) · [Research and findings](https://github.com/forest-savage1234/metabolic-engineering-forensics)

### [Decision Review Ledger](https://github.com/forest-savage1234/dfrws-lead-review)

A Python prototype that tracks the evidence behind a decision and requests human review when mapped observations change. My work includes the standalone ledger, controlled evaluation, and replay tools. The accompanying Casefile Provenance Demo presents the engine through a fictional case and comparison controls.

[Source and setup](https://github.com/forest-savage1234/dfrws-lead-review#run-the-engine) · [Open casefile demo](https://forest-savage1234.github.io/casefile-provenance-demo/) · [Evaluation and limits](https://github.com/forest-savage1234/dfrws-lead-review#original-controlled-ledger-evaluation)
